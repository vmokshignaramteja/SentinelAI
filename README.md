# SentinelAI

## AI Powered Network Intrusion Detection System

### Project Description

SentinelAI is a Flask-based Network Intrusion Detection System that captures live network packets, stores them in SQLite, and displays real-time packet statistics and security alerts through a modern web dashboard.

---

## Features

- Live Packet Monitoring
- Live Statistics Dashboard
- Live Security Alerts
- Packet Search
- SQLite Database
- Flask Backend
- Login Page
- Responsive User Interface

---

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

---

## Installation

Install the dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

Open your browser:

```
http://127.0.0.1:5000
```
